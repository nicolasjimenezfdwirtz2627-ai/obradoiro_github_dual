# Proxecto notas

Mini-proxecto para practicar o traballo en parella con Git e GitHub.

Le as notas dunha clase desde `datos/notas.csv` e mostra un informe.

```
proxecto-notas/
├── datos/            datos de entrada (CSV)
│   └── notas.csv
├── src/              código fonte do proxecto
│   ├── __init__.py
│   ├── lectura.py
│   ├── estatisticas.py
│   ├── clasificacion.py
│   └── informe.py
├── main.py           punto de entrada: executa o programa
└── probas.py         comprobacións das funcións
```

Executa sempre os comandos desde a carpeta raíz do proxecto:

- Executar o programa: `python main.py`
- Comprobar as funcións: `python probas.py`
